# 🧩 الدرس 2: تنصيب Go وبيئة التطوير

## ✅ أهداف الدرس
- معرفة كيفية تحميل وتثبيت لغة Go على مختلف أنظمة التشغيل.
- إعداد محرر الكود المناسب.
- التحقق من نجاح التثبيت وتشغيل أول برنامج.

---

## 🖥️ 1. تحميل لغة Go

لتحميل لغة Go، توجّه إلى الموقع الرسمي:

🔗 [https://go.dev/dl](https://go.dev/dl)

اختر النسخة المناسبة حسب نظام التشغيل:
- **Windows:** ملف `.msi` سهل التثبيت.
- **macOS:** ملف `.pkg`.
- **Linux:** ملف `.tar.gz`.

---

## ⚙️ 2. خطوات التثبيت حسب النظام

### ✅ Windows
1. افتح ملف التثبيت `.msi`.
2. اتبع خطوات التثبيت (Next → Next → Finish).
3. سيتم ضبط متغير البيئة `GOPATH` تلقائيًا.

### ✅ macOS
1. شغّل ملف `.pkg` وتابع التثبيت.
2. بعد التثبيت، يمكنك استخدام Go من الطرفية (`Terminal`).

### ✅ Linux
```bash
# مثال للتثبيت من الطرفية:
wget https://go.dev/dl/go1.22.0.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.22.0.linux-amd64.tar.gz

# أضف هذا إلى ملف .bashrc أو .zshrc:
export PATH=$PATH:/usr/local/go/bin
